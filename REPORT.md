## 2. Відповідь на контрольне запитання

**Запитання:** `Що таке list comprehension? Наведіть приклад`

**Відповідь:**

`List comprehension — це синтаксична конструкція в мові Python, яка дозволяє створювати нові списки на основі існуючих ітерованих об'єктів (інших списків, кортежів, рядків) у дуже стислій та читабельній формі. Вона повністю замінює собою громіздкі цикли for із використанням методу append(), дозволяючи записати логіку формування списку в один рядок коду.`


**Приклад:**

*Звичайний підхід через цикл for:*
```python
squares = []
for x in range(5):
    squares.append(x**2)
# Результат: [0, 1, 4, 9, 16]

```

*Результат через list comprehension:*

```python
squares = [x**2 for x in range(5)]
# Результат: [0, 1, 4, 9, 16]

```
